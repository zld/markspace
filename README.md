# tracecheck

Map client event times onto a unified media time base, build a random-access
index over a Matroska/WebM file, and read exact byte ranges — including files
with unknown-length EBML elements and interleaved audio/video blocks.

Everything is local. Fixtures are generated by code; there are no external
media files and no network access.

## Requirements

- macOS (Darwin) with Go 1.23+ installed (`brew install go`)
- Dependencies pinned in `go.mod`:
  - `github.com/abema/go-mp4 v1.3.0` — MP4 structure parsing / validation
  - `github.com/pion/rtp v1.8.11` — RTP header and timestamp parsing

## Build and test

```sh
go mod download
go build ./...
go test ./...
```

## Demo

```sh
go run ./cmd/tracecheck demo --work ./tmp --chunk 2
go run ./cmd/tracecheck demo --work ./tmp --chunk 2 --resume
```

The first run generates fixtures under `./tmp`, indexes the healthy sample,
reads time ranges, maps client events, cross-checks RTP/MP4, reports metadata
conflicts and damaged samples, and writes a checkpoint. The `--resume` run
reuses that checkpoint and reprocesses zero chunks; its index digest and every
`segment_sha256` are identical to the first run.

Key output lines:

- `roundtrip_rate=1.000` — indexed blocks resolve back to their exact bytes.
- `keyframe_hit_rate=…` — fraction of sampled times with a keyframe at or
  before them (≥ `0.990` for the healthy sample).
- `segment_sha256_N=…` — 64-hex SHA-256 per `[start,end)` range.
- `resume_reprocessed_chunks=0` — chunks already confirmed by the checkpoint.
- `error_offset` / `error_code` — reported damage with the byte offset and a
  stable code (`LENGTH_OUT_OF_BOUNDS`, `PARENT_BOUNDARY_CONFLICT`, …).

Exit codes:

| code | meaning |
| ---- | ------- |
| 0 | success |
| 1 | argument or local I/O failure |
| 2 | damaged input that was reported |

`tracecheck demo` exits 0 because the damaged cases are intentional fixtures
it reports on. `tracecheck check FILE` exits 2 when the named file is damaged:

```sh
go build -o ./tmp/tracecheck ./cmd/tracecheck
./tmp/tracecheck check ./tmp/truncated-block.webm   # exit 2
./tmp/tracecheck check ./tmp/healthy.webm           # exit 0
```

`sh scripts/accept.sh` runs the whole acceptance walk-through and asserts the
invariants above.

## Packages

| package | responsibility |
| ------- | -------------- |
| `internal/serr` | shared structured error (`Code`, `Offset`, `Path`) |
| `internal/ebml` | VINT, element geometry, offset-accurate parser, fixture builder |
| `internal/mkv` | interleaved blocks and normalized track/colour metadata |
| `internal/clock` | nanosecond time base and event→media mapping |
| `internal/index` | per-track keyframe index, digest, atomic checkpoints |
| `internal/range` | half-open `[start,end)` range reads |
| `internal/batch` | chunked batch runs and checkpoint resume |
| `internal/fixture` | generated WebM/MP4/log/RTP samples |
| `cmd/tracecheck` | `demo` and `check` command adapter |

### Design notes

- **Offsets are preserved exactly.** Every block keeps its absolute input
  offset and exact frame slice; block payloads are never rewritten.
- **Unknown-length elements** end at the parent boundary, EOF, or the next
  registered sibling ID that is legal in an ancestor. A registered ID that can
  close no ancestor is reported as `PARENT_BOUNDARY_CONFLICT`.
- **One time base.** Blocks, client events and RTP timestamps all convert to
  `int64` nanoseconds with overflow checks (`CLOCK_OVERFLOW`) and a shared
  error type across subsystems.
- **Metadata conflicts are recorded, not silently rewritten.** Missing values
  get explicit defaults; contradictory duplicates keep the first value and
  record the rejected one with its offset.
- **Determinism.** Re-running the same input produces the same index digest
  and per-segment hashes. Checkpoints are written atomically (temp + fsync +
  rename) and validated on resume for input digest, byte boundary and hash
  prefix.
