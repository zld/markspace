# mediacore

A local-only Go media kernel that turns timestamped MP4/MOV audio tracks into a
normalized RTP distribution manifest. It repairs what can be proven, refuses
what cannot, and reports every gap with a byte offset.

## Run

```sh
go mod tidy
go build ./...
go test ./...

# success path
go run ./cmd/mediacore demo --sample-rate 48000 --channels stereo \
  --target-kbps 128 --out /tmp/mediacore-demo.json

# recovery path
go run ./cmd/mediacore demo --fixture truncated

# dependency cycle (exit 2)
go run ./cmd/mediacore demo --fixture dep-cycle
```

Exit codes: `0` success, `1` internal/flag error, `2` dependency cycle,
`3` input that cannot be recovered.

## Fixtures

All inputs are generated by this program; no external media is read.
`mediacore fixtures --dir DIR` writes every kind:

| kind | what it proves |
| --- | --- |
| `clean` | success path, all budgets |
| `no-moov` | index rebuilt from verifiable records |
| `truncated` | readable prefix kept, gap located |
| `bad-range` | illegal sample range isolated to a gap |
| `dep-cycle` | cycle detected before any media is read |
| `wrap` | RTP timestamp wraparound keeps sequence order |
| `no-index` | stripped tables rebuilt from records |
| `garbled` | no verifiable audio, exit 3 |

Each audio sample carries a magic, sequence, frame count, and CRC32, so sample
boundaries are independently verifiable. That framing is the stated decoding
boundary: the kernel does not decode arbitrary AAC.

## Layout

| package | role |
| --- | --- |
| `internal/core` | structured errors, exit-code policy |
| `internal/timeline` | exact rational clock, sample cursor, track mapping |
| `internal/container` | bounded scan, sample validation, recovery, rescan |
| `internal/graph` | dependency graph, topological order, cycle reporting |
| `internal/audio` | layout mapping, resampling, loudness, quality stats |
| `internal/manifest` | RTP packetization, bitrate/alignment, JSON manifest |
| `internal/pipeline` | stage orchestration and stage records |
| `internal/fixture` | self-generated MP4 inputs and damage variants |
| `cmd/mediacore` | terminal entry point |

## Invariants

- **One rounding rule.** Every time conversion uses 128-bit mul/div rounding
  halves away from zero (`internal/timeline`). No other package converts time.
- **Explicit origins.** Non-zero source starts are preserved, never normalized
  away; receivers can see where the first sample sits.
- **No fabrication.** Unverifiable regions become gaps with offsets. Silence is
  never inserted to hide damage.
- **Bounded reads.** File size, box count, box depth, track count, sample
  count, and table memory are all limited; out-of-range offsets are rejected.
- **Determinism.** Identical inputs produce byte-identical manifests; resets
  are counted and reported rather than being implicit.
- **Fixed reset policy.** Each contiguous segment is processed with zeroed
  filter history; the count appears in the quality statistics.
