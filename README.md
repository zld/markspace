# mediadeliver

Turns on-site multi-camera captures into a reviewable segment manifest.
Inputs are a DASH MPD, an HLS media playlist with discontinuities, and the
fragmented MP4 files they point at. Output is a manifest that names every
interval, its representations, source offsets, digests and damage, plus a
resume cursor for interrupted runs.

Everything runs locally. Fixtures are generated by Go; no external media is
read.

## Commands

```sh
go mod tidy
go build ./...
go test ./...

go run ./cmd/mediadeliver demo   --work ./tmp/demo --faults all
go run ./cmd/mediadeliver verify --work ./tmp/demo --manifest ./tmp/demo/manifest.json
```

`demo` writes fixtures under `--work`, runs the pipeline once with an
interruption before verification, then resumes from the cursor. With
`--faults all` it additionally runs a damaged case that carries all five
injectable defects.

`verify` re-reads the manifest, recomputes its SHA-256, re-checks every
invariant and re-hashes each recorded input.

### Exit codes

| code | meaning |
| ---- | ------- |
| 0 | all checks passed |
| 2 | input or format error |
| 3 | resume cursor does not match the current inputs |
| 4 | manifest verification failed |

## Layout

| package | responsibility |
| ------- | -------------- |
| `internal/model` | integer time base (`Rational`, tick→ns with 128-bit overflow checks) and the structured `Error` carrying path, byte offset, stage and recoverability |
| `internal/dash` | MPD / SegmentTemplate / SegmentTimeline parsing, index expansion, partial-index salvage |
| `internal/hls` | media sequence, EXTINF and EXT-X-DISCONTINUITY parsing with line and byte offsets |
| `internal/segment` | streaming ISO BMFF top-level box scan, fragment boundaries, sample tables, damage classes |
| `internal/align` | maps DASH and HLS onto one nanosecond timeline and builds the manifest |
| `internal/pipeline` | stage orchestration, cursor persistence, atomic publish, invariant verification |
| `internal/fixture` | generated MPDs, playlists, fragmented MP4s and RTP packets |
| `internal/cli` | the `demo` and `verify` terminal commands |

`cmd/mediadeliver` only forwards to `internal/cli`.

## Fault classes

| class | detected by | code |
| ----- | ----------- | ---- |
| truncated box | segment scan | `truncated_box` |
| illegal box length | segment scan | `invalid_box_size` |
| zero timescale | MPD parse | `zero_timescale` |
| repeated media sequence after a discontinuity | HLS parse | `duplicate_media_sequence` |
| missing segment index | MPD parse | `missing_index` |

Each diagnostic keeps the byte offset of the offending element or box, so a
report always points back at the original input.

## Guarantees

- All conversions are integer; timestamps are converted individually, so a
  tick→ns error never accumulates.
- A shared boundary drifting more than 1 ms marks the interval
  non-deliverable (`boundary_drift`).
- Verification failures never publish a manifest; publishing uses a temp
  file plus rename in the same directory.
- The cursor stores the input digest and the completed stage. A changed
  input is rejected (exit 3) instead of reusing stale scan results. The
  demo regenerates its fixtures and drops a cursor that no longer matches.
- Repeating a run on unchanged inputs produces byte-identical manifests and
  the same SHA-256.
- Media is hashed and scanned by streaming with fixed-size buffers.
