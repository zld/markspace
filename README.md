# tsrepair

A reusable Go library for repairing and indexing MPEG-TS media streams that
cross regional distribution nodes. It unifies the time base and error model,
repairs timestamps, rebuilds a random-access index and emits per-segment
hashes so any node can independently re-verify the result.

All samples are generated by the project itself (`internal/fixture`); no
external media files are referenced.

## Requirements

- Go 1.23 (builds and tests on macOS Terminal; no external services)
- Dependencies pinned in `go.mod`:
  - `github.com/abema/go-mp4 v1.4.1` — MP4 index container
  - `github.com/pion/rtp v1.8.11` — RTP packet structure and sequence numbers

## Build and test

```sh
go mod tidy
go build ./...
go test ./...
```

## Demo

Clean, well-formed stream — all three verification rates must be 100%:

```sh
go run ./cmd/tsrepair demo --seed 7 --segment-packets 40 --queue-capacity 2
```

Faulty stream with PCR wrap, duplicate packet, continuity gap, PSI version
change, unknown audio layout and a truncated tail:

```sh
go run ./cmd/tsrepair demo --seed 7 \
  --faults wrap,duplicate,gap,psi-version,audio-layout,truncated-tail \
  --queue-capacity 1 --recover
```

### Exit codes

| Code | Meaning                                                        |
|------|----------------------------------------------------------------|
| 0    | Clean run, or recoverable faults absorbed by `--recover`       |
| 1    | Internal/implementation error                                  |
| 2    | Input cannot be interpreted safely (unrecovered input fault)   |

### Reported metrics

`parse_roundtrip`, `keyframe_hit_rate`, `segment_hash_match` (percent), plus
`repaired_wraps`, `ignored_duplicates`, `continuity_gaps`, `psi_versions`,
`audio_errors`, `truncated_bytes`, `max_queue_depth`. Confirmed portions of a
repaired stream keep 100% round-trip and hash-match rates; queue depth never
exceeds the configured capacity.

## Architecture

Data flows through bounded-queue stages; every stage uses the shared error
model and a single unwrapped time base.

```
TS/RTP bytes
  -> internal/ts        packet parsing, sync/PID/adaptation/CC validation,
                        PAT/PMT reassembly and version boundaries
  -> internal/repair    continuity check, duplicate ignore, PCR/PTS 33-bit
                        unwrap (raw and corrected values both retained)
  -> internal/metadata  audio layout/sample-rate rules, color metadata
                        input-priority conflict resolution
  -> internal/pipeline bounded queues, back-pressure, cascade cancellation
  -> internal/index     verifiable keyframe index in an MP4 container
  -> internal/segment   fixed-size segments, SHA-256, re-checkable summary
```

Supporting packages:

- `internal/model` — classified `StreamError` carrying stage, PID, byte
  offset and severity (recoverable / fatal / internal).
- `internal/timebase` — pure, deterministic 33-bit timestamp unwrap.
- `internal/fixture` — deterministic synthetic stream and fault generator.
- `internal/engine` — wires the stages into one reusable processing chain.
- `cmd/tsrepair` — thin terminal driver; it contains no processing logic.

## Key rules (encoded as tests)

- Only standard 188-byte TS packets and the agreed RTP encapsulation are
  accepted; unknown encapsulation is rejected, never guessed.
- PCR/PTS unwrap across the 33-bit modulus; a track's timeline never moves
  backwards except by a verifiable wrap. Backwards moves that cannot be a
  wrap are recoverable errors and keep the original raw value.
- PAT/PMT version changes take effect atomically at the packet boundary where
  the new current table completes; packets before/after never mis-map.
- The index admits only packets with both a unit-start and a random-access
  indicator; seeking reads back the same frame. Sparse heads are explicit
  seek misses and truncated tails are explicit errors.
- Unknown audio channel layouts and indivisible sample payloads produce
  locatable errors; nothing is silently dropped.
- Color conflicts follow input-track priority; undecidable cases preserve
  the original field and flag uncertainty. Missing vs conflicting fields are
  counted separately.
- Memory is bounded by both the inter-stage queue capacity and the maximum
  TS packet buffer (`MemoryGuard`); a slow consumer back-pressures the source.
- Recovery resumes from the last valid boundary and never resubmits a
  confirmed segment.

## Determinism

The fixture derives every byte from the seed, time repair is pure arithmetic,
and segment digests are SHA-256 over the exact stored packet ordinals. Reruns
with the same seed and flags produce byte-identical streams and identical
metrics (covered by rerun tests across packages).
