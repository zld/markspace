# mediaarchive

An auditable media-processing kernel for restoring old tape digitizations. It
analyses MP4 sample structure, subtitle cues and RTP continuity, maps every
source onto one exact rational time base, locates damaged ranges, and emits a
deterministic archive manifest that can be re-verified byte for byte.

Terminal only. No network services, no external media, no writes to inputs.

## Quick start

```sh
go mod tidy
go build ./...
go test ./...
go run ./cmd/archive analyze --fixture generated --fps 30000/1001 \
    --workers 4 --queue 8 --mode recover
```

The generated fixture set is created under `tmp/archive` and contains eight
assets covering 29.97 and 25 fps video, sustained clock drift, VFR hold frames,
an MP4 truncated mid-capture, RTP sequence/timestamp wrap, RTP loss/reorder and
subtitles with a BOM and broken cues.

## Commands

```
archive analyze [flags]     analyse fixtures or explicit inputs, print summary
archive generate [flags]    write a deterministic fixture set
archive version
```

Analyze flags: `--fixture`, `--workdir`, `--input` (repeatable), `--fps`,
`--mode recover|strict`, `--workers`, `--queue`, `--manifest`, `--csv`,
`--json`.

Exit codes: `0` complete, `1` media or processing error, `2` bad arguments.
Strict mode never prints or writes a manifest digest when it fails; the error
names the fault code and its byte offset.

## Architecture

| package | responsibility |
| --- | --- |
| `internal/clock` | exact rational seconds, SMPTE 24/25/29.97 DF+NDF/50 labels, midnight expansion, 32-bit unwrap |
| `internal/subtitle` | BOM-aware, resumable SRT and WebVTT parsing with byte-accurate faults |
| `internal/stream` | go-mp4 sample tables and keyframe gaps, pion/rtp continuity, damage segments |
| `internal/align` | least-squares drift estimation, VFR intervals from real sample time |
| `internal/merge` | deterministic total order and deduplication |
| `internal/pipeline` | bounded worker pool, per-asset analysis, manifest digest and invariants |
| `internal/diag` | shared structured faults (code + offset + media time) |
| `internal/fixtures` | pure-Go MP4 writer, pion-marshalled RTP captures, subtitle sets |

Time is carried as `clock.Rational` end to end. Float conversion happens once,
at the manifest edge, and the worst conversion error is reported as
`manifest_alignment_error_ms`.

## What the summary means

* `target_bitrate_bps` / `actual_bitrate_bps` / `bitrate_deviation_pct` —
  duration-weighted archive target versus real mdat payload rate.
* `cue_count` — accepted subtitle cues (faulty records are counted in faults).
* `damage_count` — non-overlapping locatable damage segments.
* `keyframe_gap_max_ms` — largest real inter-sync-sample span.
* `drift_ppm` — median keyframe-cadence deviation from the declared frame rate.
* `manifest_alignment_error_ms` — worst rational-to-float drift in any row.
* `manifest_sha256` — digest of mode, rows, segments and faults. Identical for
  identical input regardless of worker scheduling.

## Fixtures

Fixtures are generated by `internal/fixtures`, never committed as media. See
`testdata/README.md` for the per-set matrix. `go run ./testdata/generate.go`
materialises them on disk for manual inspection.
