# mediacore

A local, reusable Go media-processing kernel for aligning sparse MP4 keyframes,
edit lists, non-zero timestamps and RTP metadata on one event timeline.

No media pixels or audio samples are decoded. Fixture MP4/RTP material is
generated by code; the only third-party runtime dependencies are
`github.com/abema/go-mp4 v1.3.0` and `github.com/pion/rtp v1.8.9`.

## Run acceptance

```bash
brew install go          # only if Go is not already installed
go mod tidy
go build ./...
go test ./...

go run ./cmd/mediacore demo \
  --fixture generated \
  --range 00:10:00,00:10:12 \
  --crash-after publish \
  --rerun

go run ./cmd/mediacore demo --fixture corrupt --all
```

Or run `scripts/acceptance.sh`.

The generated demo prints:

- `parse_roundtrip_rate` and `parse_roundtrip_percent`
- `keyframe_hit_rate` and `keyframe_hit_percent`
- deterministic `segment_hashes`
- `recovered_artifacts=1`
- `duplicate_publications=0`
- `error_offsets`

Corrupt mode reports each expected error category and its non-negative raw byte
offset and leaves `verified_marker=false`.

## Exit codes

- `0`: all acceptance assertions passed
- `1`: an acceptance/recovery assertion failed
- `2`: command arguments or input paths are invalid

When run through `go run`, the Go tool itself may normalize a child exit code
such as `2` to its own exit status `1`; the compiled `./mediacore` binary
preserves the specified code directly. The success acceptance commands return
zero through `go run`.

## Packages

- `internal/clock`: event/media time conversion, edit-list mapping and located errors
- `internal/mp4`: box-boundary scanner, go-mp4 table/edit decoding, RTP header widening
- `internal/index`: random-access keyframe index and half-open range queries
- `internal/pipeline`: atomic hashed artifacts, state commit, recovery and idempotent publish
- `internal/fixture`: deterministic normal, long-timeline and corrupt samples
- `cmd/mediacore`: terminal demo/acceptance CLI

Pipeline state and generated files live under `.mediacore-demo/` and are ignored
by Git.
