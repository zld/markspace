# archivecheck

A local, dependency-light media processing core for long-term archive recovery.
It locates damaged regions in MP4, RTP and subtitle sources on one nanosecond
time scale, resumes interrupted runs from verified byte boundaries, and writes
a content-addressed, independently verifiable manifest.

Everything runs offline against local files. There is no GUI, no network
service and no external media sample: every fixture is generated by the code.

## Requirements

- macOS (Darwin) with a terminal
- Go 1.23

Dependencies are pinned in `go.mod`:

- `github.com/abema/go-mp4 v1.4.1` for MP4 box parsing
- `github.com/pion/rtp v1.8.11` for RTP header parsing

## Build and test

```sh
go mod tidy
go build ./...
go test ./...
```

## Demo

```sh
go run ./cmd/archivecheck demo --out /tmp/archive-demo --chunk 4096 --queue 2
```

The demo generates six samples, streams them through the bounded pipeline,
runs the structural and timeline analyses, and writes a verified manifest:

| sample                 | purpose                                      |
| ---------------------- | -------------------------------------------- |
| `clip-valid.mp4`       | structurally valid MP4, keyframes every 25th sample |
| `clip-truncated.mp4`   | same MP4 cut short inside `mdat`             |
| `capture-loss.rtp`     | RTP capture with two sequence gaps           |
| `subs-recoverable.srt` | SRT with two recoverable damage sites        |
| `subs-valid.vtt`       | WebVTT with identifiers, settings, multiline cues |
| `timecodes.txt`        | valid and invalid timecodes for every rate   |

The run prints, in order: source digests, per-stage status, interruption cause
and resume offset, damaged byte spans, keyframe offsets and intervals,
recovered cues, rejected timecodes, derivative reuse counts and the manifest
checksum. It exits `0` only when every assertion passes.

Re-running the same command reuses every derivative (`added=0`) and produces
the same manifest checksum.

## Verify an archive

```sh
go run ./cmd/archivecheck verify --out /tmp/archive-demo
```

`verify` recomputes the manifest checksum, re-hashes every derivative file,
checks that derivative keys match their dependency digests, and confirms the
recorded added/reused/changed counts add up to the listed artefacts.

## Layout

| package              | responsibility                                          |
| -------------------- | ------------------------------------------------------- |
| `internal/fault`     | one error type carrying stage, source, kind and byte offset |
| `internal/timebase`  | the shared nanosecond scale and frame-rate arithmetic    |
| `internal/asset`     | digest-addressed, read-only, path-contained source access and atomic writes |
| `internal/subtitle`  | SRT and WebVTT parsing with recoverable-cue scanning     |
| `internal/timecode`  | 24/25/29.97 DF/NDF/50 timecode parsing and formatting   |
| `internal/stream`    | MP4 box/keyframe analysis and RTP sequence analysis     |
| `internal/pipeline`  | bounded chunk/queue streaming with shared cancellation  |
| `internal/recovery`  | per-stage checkpoints with verified resume boundaries   |
| `internal/manifest`  | layered content-addressed derivatives and the manifest  |
| `internal/fixture`   | deterministic, code-generated media samples             |
| `cmd/archivecheck`   | `demo` and `verify` entry points                       |

## Design notes

- **One scale, one error model.** Every timestamp is `timebase.Nanos`; every
  failure is a `fault.Err` with a stage, a source and a byte offset.
- **Offsets survive damage.** Subtitle parsing records a problem and keeps
  scanning, so a truncated archive still yields its recoverable cues. MP4 and
  RTP analysis report the first damaged byte of each broken region.
- **Bounded memory.** A stage blocks on a full downstream queue, which stalls
  the source reader. The number of live chunks is bounded by
  `(stages+1) * (queueSize+1)` regardless of input length.
- **Verified resume.** A checkpoint stores each stage's byte boundary and the
  SHA-256 of the source prefix before it. A changed source digest, a changed
  pipeline shape or a corrupted prefix all reject the checkpoint. A restart
  rewinds every stage to the lowest verified boundary so the resumed run stays
  consistent.
- **Layered invalidation.** A derivative's key hashes its kind, layer and
  dependency digests; its file name is the digest of its bytes. Changing one
  source therefore changes exactly the keys that depend on it.
- **Safe I/O.** Reads are confined to the input root, including through
  symlinks. Every output is written to a temporary file, fsynced and renamed
  into place.
